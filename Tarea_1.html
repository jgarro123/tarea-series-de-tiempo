Gráficas de las series y sus ACF

# Se divide el espacio gráfico en dos partes para comparar cada serie con su ACF.
par(mfrow = c(1, 2))

# Se recorre la lista y se trabaja con una serie a la vez.
for (nombre in names(series_A)) {
  # A la izquierda se dibuja la evolución de los valores en el tiempo.
  plot(series_A[[nombre]], type = "l", main = nombre,
       xlab = "Tiempo", ylab = "Valor")

  # Se usa aproximadamente la cuarta parte de los datos como número de rezagos.
  n <- length(series_A[[nombre]])
  m <- floor(n / 4)

  # Se calcula la ACF hasta el rezago m sin dibujarla todavía.
  resultado_acf <- acf(series_A[[nombre]], lag.max = m, plot = FALSE)
  rezagos <- as.numeric(resultado_acf$lag)[-1]
  correlaciones <- as.numeric(resultado_acf$acf)[-1]

  # La banda azul supone que la serie es ruido blanco.
  banda_blanca <- qnorm(0.975) / sqrt(n)

  # La banda roja de Bartlett cambia según las correlaciones anteriores.
  sumas_previas <- c(0, cumsum(correlaciones[-length(correlaciones)]^2))
  banda_bartlett <- qnorm(0.975) * sqrt((1 + 2 * sumas_previas) / n)

  # A la derecha se dibuja la ACF y se añaden ambas bandas de confianza.
  plot(rezagos, correlaciones, type = "h", ylim = c(-1, 1),
       main = paste("ACF de", nombre), xlab = "Rezago", ylab = "ACF")
  abline(h = 0)
  abline(h = c(-banda_blanca, banda_blanca), col = "blue", lty = 2)
  lines(rezagos, banda_bartlett, col = "red", lty = 3)
  lines(rezagos, -banda_bartlett, col = "red", lty = 3)
  legend("topright", c("Ruido blanco", "Bartlett"),
         col = c("blue", "red"), lty = c(2, 3), cex = 0.8)
}

Prueba de Ljung–Box

La prueba de Ljung–Box permite evaluar conjuntamente las autocorrelaciones desde el rezago 1 hasta el rezago 24.

Hipótesis de la prueba

Hipótesis nula:

\[ H_0: \rho_1 = \rho_2 = \cdots = \rho_{24} = 0 \]

La serie no presenta autocorrelación en los primeros 24 rezagos y se comporta como ruido blanco.

Hipótesis alternativa:

\[ H_1: \rho_k \neq 0 \quad \text{para al menos un } k \in \{1,\ldots,24\} \]

La serie presenta autocorrelación en al menos uno de los primeros 24 rezagos.

Se utiliza un nivel de significancia de \(\alpha=0.05\). Si el valor p es menor que 0.05, se rechaza \(H_0\); en caso contrario, no se rechaza \(H_0\).

# Se crea una tabla vacía para guardar el resultado de cada prueba.
tabla_ljung <- data.frame()

# Se aplica la prueba de Ljung-Box con 24 rezagos a cada serie.
for (nombre in names(series_A)) {
  prueba <- Box.test(series_A[[nombre]], lag = 24, type = "Ljung-Box")

  # Se guardan el estadístico Q y el valor p obtenidos para la serie.
  tabla_ljung <- rbind(
    tabla_ljung,
    data.frame(
      Serie = nombre,
      Q = as.numeric(prueba$statistic),
      p = format.pval(prueba$p.value, digits = 3, eps = 0.001)
    )
  )
}

# Se presenta la tabla con el estadístico Q redondeado a tres cifras.

La hipótesis nula afirma que las autocorrelaciones de los primeros 24 rezagos son iguales a cero. En las cuatro series el valor p es menor que 0.001. Por lo tanto, con un nivel de significancia del 5 %, se rechaza la hipótesis nula en todos los casos. Esto indica que las cuatro series presentan dependencia temporal y no se comportan como ruido blanco.

Ruta 2: nivel y amplitud por año

Para cada año, el nivel medio es el promedio de sus cuatro observaciones trimestrales. La amplitud estacional es la diferencia entre el trimestre con mayor consumo y el trimestre con menor consumo del mismo año.

# La función matrix organiza el vector y_ruta2 en una tabla.
# ncol = s2 crea cuatro columnas, porque cada año tiene cuatro trimestres.
# byrow = TRUE coloca cada grupo de cuatro datos consecutivos en una misma fila.
datos_anuales <- matrix(y_ruta2, ncol = s2, byrow = TRUE)

# Cada fila de datos_anuales representa un año entre 1960 y 1986.
anios <- 1960:1986

# rowMeans calcula el promedio de cada fila.
# El resultado es un vector con un nivel medio para cada año.
nivel_medio <- rowMeans(datos_anuales)

# apply recorre la matriz por filas porque MARGIN = 1.
# Para cada año, max obtiene el valor mayor y min obtiene el menor.
# La resta entre ambos valores produce la amplitud estacional anual.
amplitud_estacional <- apply(
  datos_anuales,
  MARGIN = 1,
  FUN = function(valores) max(valores) - min(valores)
)

# data.frame reúne los tres vectores en columnas de una sola tabla.
# Cada fila contiene el año, su nivel medio y su amplitud estacional.
resumen_ruta2 <- data.frame(
  Año = anios,
  Nivel_medio = nivel_medio,
  Amplitud_estacional = amplitud_estacional
)

Correlogramas de las dos rutas

# Este vector guarda el período estacional de cada serie.
# El primer valor corresponde a nottem y el segundo a UKgas.
periodos_rutas <- c(s1, s2)

# par divide la figura en dos columnas para mostrar un correlograma por ruta.
par(mfrow = c(1, 2))

# seq_along produce las posiciones 1 y 2 para recorrer ambas series.
for (i in seq_along(rutas)) {
  # [[i]] extrae la serie situada en la posición i de la lista rutas.
  serie <- rutas[[i]]

  # length cuenta los datos y floor toma la parte entera de T/4.
  T <- length(serie)
  m <- floor(T / 4)

  # acf calcula las autocorrelaciones hasta m, pero no las grafica todavía.
  resultado <- acf(serie, lag.max = m, plot = FALSE)

  # $lag y $acf extraen los rezagos y las autocorrelaciones del resultado.
  # [-1] elimina el rezago 0, cuya autocorrelación siempre es igual a 1.
  rezagos <- as.numeric(resultado$lag)[-1]
  correlaciones <- as.numeric(resultado$acf)[-1]

  # La primera expresión calcula la banda constante de ruido blanco.
  banda_blanca <- qnorm(0.975) / sqrt(T)

  # cumsum acumula los cuadrados de las correlaciones anteriores.
  # Estas sumas permiten que la banda de Bartlett cambie con el rezago.
  sumas_previas <- c(0, cumsum(correlaciones[-length(correlaciones)]^2))
  banda_bartlett <- qnorm(0.975) * sqrt((1 + 2 * sumas_previas) / T)

  # plot dibuja las autocorrelaciones como líneas verticales.
  # names(rutas)[i] toma el nombre de la serie para formar el título.
  plot(rezagos, correlaciones, type = "h", ylim = c(-1, 1),
       main = paste("ACF de", names(rutas)[i]),
       xlab = "Rezago", ylab = "ACF")
  abline(h = 0)

  # Las líneas azules corresponden a la banda de ruido blanco.
  abline(h = c(-banda_blanca, banda_blanca), col = "blue", lty = 2)

  # Las líneas rojas corresponden a los dos límites de Bartlett.
  lines(rezagos, banda_bartlett, col = "red", lty = 3)
  lines(rezagos, -banda_bartlett, col = "red", lty = 3)

  # legend explica el color y el tipo de línea de cada banda.
  legend("topright", c("Ruido blanco", "Bartlett"),
         col = c("blue", "red"), lty = c(2, 3), cex = 0.8)

Prueba de Ljung–Box para las dos rutas

En cada serie se utiliza \(m=4s\). Por ello, la ruta 1 usa 48 rezagos y la ruta 2 usa 16.

Hipótesis nula:

\[ H_0: \rho_1 = \rho_2 = \cdots = \rho_{4s} = 0 \]

La serie no presenta autocorrelación en los primeros \(4s\) rezagos.

Hipótesis alternativa:

\[ H_1: \rho_k \neq 0 \quad \text{para al menos un } k \in \{1,\ldots,4s\} \]

La serie presenta autocorrelación en al menos uno de los primeros \(4s\) rezagos.

# Se crea una tabla vacía para almacenar una prueba por cada ruta.
tabla_ljung_rutas <- data.frame()

# El ciclo aplica el mismo procedimiento a las dos series.
for (i in seq_along(rutas)) {
  serie <- rutas[[i]]
  s <- periodos_rutas[i]

  # La cantidad de rezagos de la prueba se obtiene multiplicando 4 por s.
  m_ljung <- 4 * s

  # Box.test aplica la prueba y devuelve, entre otros datos, Q y el valor p.
  prueba <- Box.test(serie, lag = m_ljung, type = "Ljung-Box")

  # rbind agrega los resultados de la serie actual como una nueva fila.
  tabla_ljung_rutas <- rbind(
    tabla_ljung_rutas,
    data.frame(
      Serie = names(rutas)[i],
      m = m_ljung,
      Q = as.numeric(prueba$statistic),
      p = format.pval(prueba$p.value, digits = 3, eps = 0.001)
    )
  )
}
